## What it does

`main.ts` (Node 22, standard library only, deterministic, no network) writes
a single roast line about a robot vacuum to `/output/entry.txt`:

> My robot vacuum mapped the dog, filed him under 'furniture,' and now cleans around him like he's a chair I can't return.

## Run

```sh
node main.ts
cat /output/entry.txt
```
